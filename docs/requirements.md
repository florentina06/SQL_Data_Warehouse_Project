# Building the Data Warehouse (Data Engineering)

## Objective
Build a modern data warehouse in PostgreSQL that brings sales data together in one place and supports analytical reporting and better decisions.

## Specifications

* **Data Sources:** Load data from two source systems (ERP and CRM), delivered as CSV files
* **Data Quality:** Clean the data and fix quality issues before any analysis
* **Integration:** Merge both sources into one simple data model built for analytical queries
* **Scope:** Use only the most recent dataset; no historization needed
* **Documentation:** Document the data model clearly for both business users and analytics teams
